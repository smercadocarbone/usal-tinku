# ADR-000-06 — Proveedor de email transaccional: Resend (plan gratuito)

**Estado:** Aceptado — 2026-09-24 (decisión P5, `docs/superpowers/specs/remediacion/00-LEEME-opencode.md` §5)

## Contexto

AUD-008/AUD-014: "olvidé mi contraseña" no funciona porque no existe ningún canal fuera de la
app (el usuario sin sesión no puede ver la bandeja in-app de FASE2-03). Hace falta un proveedor de
email transaccional. Restricciones del Artículo VII: 1 desarrollador, USD 0-100/mes; en el piloto
el volumen es de decenas de emails por día (resets de contraseña y avisos puntuales).

El dominio del proyecto ya está en Cloudflare. Se evaluó:

| Opción | Costo para el piloto | Notas |
|---|---|---|
| **Resend, plan gratuito** | USD 0 | 3.000 emails/mes, tope 100/día. API HTTP con un POST y una API key. |
| Brevo, plan gratuito | USD 0 | 300/día. API parecida; panel orientado a marketing. |
| Cloudflare Email Service | USD 5/mes | Beta pública desde abril 2026; exige el plan Workers Paid y enviar desde un Worker (otro runtime que mantener). |
| Amazon SES | ~USD 0,10/1.000 | Requiere salir del sandbox de AWS y una cuenta más que administrar. |
| SMTP propio | USD 0 | Entregabilidad pobre sin reputación de IP; descartado. |

## Decisión

**Resend en su plan gratuito**, llamado por HTTP desde el backend con el `java.net.http.HttpClient`
del JDK: **sin dependencia nueva** en Maven. Cloudflare se usa solo como DNS del dominio para
publicar los registros que Resend pide (SPF, DKIM y, recomendado, DMARC).

- El adaptador vive detrás de un puerto (`Notificador` de FASE2-03 / `NotificadorResetPassword`):
  cambiar de proveedor es cambiar un bean.
- **Fail-closed sin configuración:** sin `RESEND_API_KEY` (y el remitente verificado), el adaptador
  no envía y deja el aviso en el outbox con un log; nunca inventa un envío.
- Reintentos por Quartz persistido (A4), con el backoff de la Tabla de Tiempos.
- Nunca se manda en un email un dato de un menor más allá de lo imprescindible (Artículo II).

## Consecuencias

- **Tope de 100 emails/día** del plan gratuito. Si el piloto lo supera, el plan pago de Resend
  entra en el presupuesto (USD 20/mes) o se pasa a SES; es un cambio de adaptador.
- Pasos manuales del usuario (fuera del código): crear la cuenta en Resend, agregar el dominio,
  copiar los registros DNS a Cloudflare y cargar la API key como variable de entorno del backend.
